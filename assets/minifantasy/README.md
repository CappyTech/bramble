# Minifantasy assets (not committed)

Everything in this folder except this file is gitignored. The Minifantasy packs by
Krishna Palacio are licensed for use in this game but may not be redistributed, so
they must never be committed while the repo's visibility is undecided (brief, open
question 3).

To set up a dev machine: download the owned packs from https://krishna-palacio.itch.io/
and unpack each one into its own subfolder here, e.g.

    assets/minifantasy/farm/
    assets/minifantasy/forgotten_plains/

Credit "Krishna Palacio" in the game credits and send a link on release (licence terms).
